# Product demo page

Prepare a guided product demonstration document.

Explain the scenario, starting state, steps, observed outcome, and what to try next. Link an existing demo or recording and disclose prerequisites.

No live embedded application or new video is created. Use static walkthroughs and supplied external demo links.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
