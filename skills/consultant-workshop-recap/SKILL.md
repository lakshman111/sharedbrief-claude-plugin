# Workshop recap

Turn workshop notes into a usable decision record.

Group topics, actual decisions, unresolved questions, disagreements, and actions with owners and dates where provided. Attribute statements only when notes support them.

Do not portray consensus or action ownership that participants did not agree to.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
