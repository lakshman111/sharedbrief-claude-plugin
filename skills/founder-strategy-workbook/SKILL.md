# Strategy workbook

Create a structured founder decision exercise.

Frame the decision, goals, constraints, competing options, tradeoffs, assumptions to test, and next experiments. Use tables for a written scenario comparison.

A static workbook does not save interactive answers or execute experiments; avoid presenting strategic hypotheses as proven.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
