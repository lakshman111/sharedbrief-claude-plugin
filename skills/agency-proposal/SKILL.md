# Proposal

Prepare an agency engagement proposal.

Set out strategy, deliverables by phase, team responsibilities, revision limits, schedule assumptions, client dependencies, and supplied pricing.

Do not promise unlimited revisions, results, or rights transfers without approved terms.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
