# Case study

Explain a documented customer result for prospective buyers.

Describe the starting problem, intervention, implementation context, measured outcome, and limitations. Attribute numbers and quotes to supplied evidence. Distinguish customer-approved material from a draft awaiting approval.

Never invent testimonials, claim causation from correlation, or identify a customer without authorization.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
