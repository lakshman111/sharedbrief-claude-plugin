# Plain-language editing

Rewrite selected text using concrete subjects, active verbs, useful detail, and a tone suited to the reader. Remove repetition, empty praise, vague claims, and unnecessary jargon. Preserve meaning, uncertainty, attribution, quotations, numbers, and commitments. Do not invent anecdotes, erase material caveats, or promise to evade AI detectors. Show a revised draft before saving when the user asked only for copy suggestions; edit the stored brief only when requested. A concise professional voice is the goal, not a claim that text was written by a human.

Before changing a stored document, read [SharedBrief workflow](../../references/brief-workflow.md) and preserve its current revision, access, publication state, and stable URL.
