# Brief

Prepare a compact decision-oriented document.

State the audience, problem, context, evidence, recommendation or options, uncertainties, and next decision. Use the user’s requested purpose to determine emphasis.

Avoid duplicating specialized workflows when a specific proposal, research, or report skill better matches the request.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
