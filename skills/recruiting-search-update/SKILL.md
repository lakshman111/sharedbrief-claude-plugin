# Search update

Report recruiting search progress.

Summarize the reporting window, funnel stages with supplied counts, pipeline changes, blockers, client decisions, and next actions. Keep candidate details to the minimum needed.

Do not identify candidates without permission or confuse pipeline activity with hiring success.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
