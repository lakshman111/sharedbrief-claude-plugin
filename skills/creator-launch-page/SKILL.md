# Launch page

Announce a creator’s new offer.

Explain the audience, offer, value, format, launch date, price if known, proof, and one action using a supplied destination.

Do not invent scarcity, guarantees, testimonials, or checkout functionality.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
