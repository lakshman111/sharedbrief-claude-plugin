# Open house page

Prepare an informational property-event page.

Include verified property details, time with timezone, location authorized for publication, access instructions, host contact, and an existing RSVP route.

No built-in registration form or live RSVP tracking. Do not expose private occupant details.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
