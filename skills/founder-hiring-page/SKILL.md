# Hiring page

Describe a role and team for prospective applicants.

Include role purpose, actual responsibilities, reporting context, required qualifications, compensation/location if supplied, hiring process, and an existing application route.

Do not invent employment terms, discriminatory criteria, benefits, or a working application form.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
