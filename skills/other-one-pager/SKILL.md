# One-pager

Condense a topic into a focused one-page-style brief.

Select the main message, necessary context, evidence, practical details, and next action. Prefer a short document over compressing unreadably.

Do not guarantee print pagination or PDF export; return a readable hosted document.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
