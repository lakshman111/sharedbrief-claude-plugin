# Sales funnel page

Present an offer with a clear path to a next conversation.

Explain the audience problem, proposed outcome, proof, relevant pricing if known, objections, and one call to action. Use an existing booking or contact URL when supplied.

This is a static offer document, not a functioning funnel automation, CRM connection, payment page, or built-in form.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
