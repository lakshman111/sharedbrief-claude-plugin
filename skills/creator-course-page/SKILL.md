# Course page

Describe an educational offer for prospective learners.

State intended learners, prerequisites, learning objectives, curriculum, format, access details, price if supplied, and supported outcomes. Use an existing enrollment URL.

Do not claim accreditation, guaranteed income, or a working payment/enrollment flow.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
