# Candidate profile

Summarize supplied professional candidate information for a hiring team.

Record relevant experience, stated skills, role fit evidence, work examples, and questions to validate. Distinguish candidate statements from independently confirmed information.

Include only job-relevant permissioned information. Exclude sensitive personal traits; do not make selection decisions or fabricate credentials.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
