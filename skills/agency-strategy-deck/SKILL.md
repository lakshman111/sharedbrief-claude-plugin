# Strategy deck

Outline an agency strategy presentation.

Use numbered document sections for diagnosis, audience insight, strategic choice, creative direction, channel roles, sequencing, measurement, and risks.

Produce a static document outline, not an actual slide-deck export; label speculative concepts.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
