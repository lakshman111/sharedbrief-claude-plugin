# Buyer guide

Help a property buyer organize a comparison.

Use the buyer supplied criteria, property facts, financing questions, inspection items, tradeoffs, and decision checklist. Identify which facts require an agent or professional to verify.

Do not give definitive legal, lending, or investment advice or steer buyers using demographic/protected-class characteristics.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
