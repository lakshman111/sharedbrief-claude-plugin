# Strategy brief

Present a consultant recommendation and its rationale.

Frame the client problem, alternatives considered, recommendation, evidence, tradeoffs, sequencing, and validation milestones. Include assumptions and what would change the recommendation.

Keep recommendations proportionate to the evidence and preserve confidentiality in shared versions.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
