# Pricing calculator

Explain a pricing estimate using supplied rates and quantities.

Show the pricing rule, units, exclusions, input values, calculation, and a few labeled scenarios. State currency, period, rounding, and whether taxes or other charges are included. Flag missing inputs rather than assume a rate.

Output a static calculation worksheet. No live sliders, scripts, payment processing, or automatic quotes; link an existing calculator only if supplied.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
