# Personalized outbound page

Create an account-specific introduction a seller can share.

Use supplied account facts to state a relevant problem hypothesis, focused offer, supporting evidence, and one next step. Keep personalization factual and respectful, and distinguish what is known from what should be tested.

Do not manufacture familiarity, scrape personal data, or send outreach. Creation and sending are separate actions.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
