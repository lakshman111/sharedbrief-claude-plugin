# Fundraising deck

Outline an investor presentation in a shareable document.

Write numbered sections for problem, solution, customer evidence, market assumptions, business model, traction, competition, team, financial assumptions, and raise/use of funds. Use supplied figures and dates.

Produce a document with slide-like sections, not a PowerPoint file or investment recommendation. Do not invent traction or disclose private investor details.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
