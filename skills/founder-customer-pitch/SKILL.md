# Customer pitch

Explain a product to a specific prospective customer.

Connect the customer problem to product capabilities, credible evidence, implementation needs, and a next step. Separate available features from planned work.

Avoid invented product metrics, unsupported guarantees, and claims that a roadmap feature is live.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
