# Campaign recap

Review a completed marketing campaign.

State objectives, time window, audience, spend if supplied, activity, results, attribution limits, lessons, and next tests. Preserve metric definitions and denominators.

Do not infer causality or profitability from impressions alone.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
