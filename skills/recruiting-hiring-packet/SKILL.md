# Hiring packet

Organize materials for a hiring loop.

Include the role definition, evaluation criteria, interview responsibilities, candidate materials authorized for sharing, process milestones, and open questions.

Use restricted sharing for candidate data; do not infer protected traits or present an automated hiring decision.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
