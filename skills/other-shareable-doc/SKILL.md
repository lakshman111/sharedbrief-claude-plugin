# Shareable doc

Prepare selected content as a readable hosted document.

Preserve the user’s intended meaning, audience, structure, links, and important detail. Clean up formatting without expanding scope or silently removing caveats.

Share only content the user selected; do not extract private history or automatically publish an entire conversation.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
