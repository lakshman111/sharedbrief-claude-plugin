# Sponsor pitch

Prepare a sponsorship proposal for a named brand.

Explain audience fit, proposed deliverables, timing, supplied reach/evidence, disclosure expectations, budget if provided, and next decision.

Do not invent sponsor commitments or metrics; draft copy does not publish advertising or send a pitch.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
