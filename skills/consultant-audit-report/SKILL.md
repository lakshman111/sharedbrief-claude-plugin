# Audit report

Document an evidence-backed assessment for a client.

State scope, method, findings, evidence, severity or business consequence, recommended corrections, ownership, and limitations. Distinguish directly observed facts from inferred causes.

Do not claim checks were performed or certify compliance when evidence is missing.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
