# Portfolio page

Curate professional work for a particular audience.

Choose supplied work examples, explain role/contribution, constraints, results, and links to authorized assets. Make relevance and next contact action clear.

Do not claim ownership of collaborators’ work or publish confidential client artifacts.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
