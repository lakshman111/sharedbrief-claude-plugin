# Media kit

Present a creator’s verified audience and collaboration options.

Include positioning, audience metrics with dates and platform definitions, relevant work, approved partnerships, supplied packages/rates, and contact route.

Do not inflate metrics, imply endorsement, or include private audience information.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
