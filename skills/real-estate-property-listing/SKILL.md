# Property listing

Describe a property using authorized facts and assets.

Organize features, layout, condition, supplied price/status, material notes, authorized photo links, and viewing instructions. Date availability information.

Do not invent measurements, amenities, approval status, or photo ownership; no new MLS submission is made.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
