# ROI business case

Build a transparent economic case for a proposed purchase.

Separate baseline inputs, proposed changes, implementation costs, recurring costs, estimated benefits, and uncertainty. Show arithmetic with units and time periods. Compare conservative and optimistic scenarios when inputs justify them.

Do not invent savings or claim an expected return is guaranteed. Leave the case unquantified when baseline economics are missing.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
