# Client report

Summarize consulting delivery and outcomes.

Organize completed work, measured outcomes, work in progress, decisions needed, risks, and upcoming actions. Date the reporting period and identify data limitations.

Do not conflate activity with impact or hide missed deliverables.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
