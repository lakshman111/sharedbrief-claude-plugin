# Market report

Summarize supplied local property-market evidence.

State geographic scope, date range, data sources, comparable criteria, prices, inventory, trend calculations, and limitations. Separate observations from projections.

No invented current comps, valuations, forecasts, or demographic steering.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
