# Role brief

Clarify a recruiting search mandate.

State actual responsibilities, required and optional experience, reporting structure, compensation/location if supplied, interview process, and sourcing priorities.

Do not invent compensation, legal requirements, or exclusion criteria unrelated to the work.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
