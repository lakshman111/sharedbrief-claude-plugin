# Performance report

Explain client marketing results and implications.

Present the reporting period, source, metric definitions, targets, actual values, comparisons, data quality, and recommended tests. Separate facts from interpretation.

State missing attribution or incomplete tracking; never fabricate benchmarks or calculated results.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
