# Client proposal

Define a consulting engagement for review.

Describe the client decision, approach, deliverables, timeline assumptions, client inputs, exclusions, fees if supplied, and how scope changes are handled.

Do not create binding commitments, guaranteed results, or approved fees from tentative notes.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
