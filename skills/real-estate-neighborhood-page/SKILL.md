# Neighborhood page

Present factual local information for property research.

Describe supplied amenities, transit, distances, services, and dated sources. Link official resources and identify unknown facts.

Avoid protected-class descriptions, demographic steering, and unsupported safety or school-quality claims.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
