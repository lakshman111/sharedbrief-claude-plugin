# Interview plan

Design a job-relevant structured interview guide.

Align questions and observable scoring anchors to role competencies. Include interviewer assignments, timing, consistent prompts, and a place to record evidence.

Exclude questions about protected or sensitive personal characteristics. A static scorecard does not collect responses or decide eligibility.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
