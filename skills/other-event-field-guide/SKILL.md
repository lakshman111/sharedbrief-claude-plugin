# Event field guide

Curate a practical event-selection guide.

Use dated supplied schedules to compare topics, people, locations, attendance requirements, and itinerary options. Note conflicts and verify timezone assumptions.

No invented events or guaranteed admission; avoid exposing private attendee information.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
