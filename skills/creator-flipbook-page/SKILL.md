# Flipbook page

Organize material into a page-by-page reading sequence.

Create numbered sections with concise copy, captions for authorized assets, and clear navigation headings. Preserve sequence and reading order.

Deliver a static paginated-style document, not animated page turning, JavaScript, or a flipbook application.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
