# Report

Organize evidence and analysis for readers.

Define scope and date, methods or sources, findings, interpretation, limitations, conclusions, and recommendations. Preserve metric definitions and source attribution.

Do not claim research or tests happened when they did not; distinguish supplied data from inference.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
