# Deal room

Assemble a buyer-facing hub for an active opportunity.

Summarize goals, evaluation status, stakeholders, milestones, open risks, and next decisions. Link approved proposal, evidence, and other resources with clear labels. Distinguish one linked hub from a collection of newly created documents.

Use existing supplied URLs; do not create a data room, upload files, or invent document availability. Confirm the intended reader audience.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
