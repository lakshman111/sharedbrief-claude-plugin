# Launch page

Announce a founder-led product release.

State who the release helps, what is available now, the main benefit, proof or example, launch date, and access instructions. Separate beta constraints and upcoming work.

Do not claim public availability, integrations, or pricing that the user has not confirmed.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
