# Champion enablement page

Help a known buyer champion explain a proposed purchase internally.

Organize the decision, business problem, stakeholder concerns, evidence, costs, implementation responsibilities, and unresolved approvals. Make the argument easy to reuse while identifying assumptions.

Do not imply the champion or other stakeholders have endorsed the proposal unless supplied facts show it.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
