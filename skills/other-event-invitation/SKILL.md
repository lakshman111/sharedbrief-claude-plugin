# Event invitation

Prepare an invitation document for a defined audience.

Include purpose, hosts, date/time/timezone, approved venue details, agenda, access requirements, and an existing reply or RSVP link.

Do not send invitations or claim a registration/RSVP system exists.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
