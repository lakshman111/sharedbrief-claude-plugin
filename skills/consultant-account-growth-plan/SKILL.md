# Account growth plan

Plan expansion within an existing client relationship.

Start from delivered value and documented client priorities. Identify credible expansion hypotheses, stakeholders, evidence gaps, risks, and next validation conversations.

Use permissioned client facts and label opportunities as hypotheses rather than promised revenue.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
