# Event landing page

Describe an event and how to participate.

Present audience fit, agenda, verified speakers, date/time, venue or access instructions, price if supplied, and an existing registration destination.

A static page does not process registrations, ticket sales, calendar updates, or reminders.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
