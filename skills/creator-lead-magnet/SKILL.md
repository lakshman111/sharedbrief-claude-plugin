# Lead magnet

Create a useful audience resource tied to an offer.

Deliver concrete reference material such as a checklist, worksheet, or guide; explain who it helps and an optional next step. Keep practical value ahead of promotion.

A document alone is not an email gate. Do not claim capture settings were enabled; use the dashboard only when the user asks and capabilities support it.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
