# Creative brief

Define direction for creative production.

Document audience, objective, core message, tone, channels, deliverables, mandatory assets, constraints, approval process, and success criteria.

Do not invent brand guidelines or imply supplied assets are licensed for every use.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
