# Landing page

Present one clearly defined offer in a shareable page.

Explain the audience problem, offer, evidence, key details, objections, and a single supplied next-action link. Match the user’s tone and avoid unsupported promotional claims.

No form backend, payment processing, custom domain setup, or conversion automation is implied.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
