# Talent pitch

Explain an opportunity to a potential candidate.

Describe the actual work, team, opportunity, expectations, process, and approved compensation details. Address known candidate priorities without claiming private knowledge.

Do not send recruitment messages or invent benefits, sponsorship, or guaranteed outcomes.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
