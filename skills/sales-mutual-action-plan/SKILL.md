# Mutual action plan

Document a shared evaluation or implementation plan.

Create a milestone table with deliverable, owner, target date, dependency, acceptance evidence, and status. Highlight decisions requiring agreement and the effect of blocked dependencies.

Label proposed dates and responsibilities as proposed; a plan is not evidence of buyer commitment.

Before saving, publishing, revising, or checking a brief, read [SharedBrief workflow](../../references/brief-workflow.md). Use only the content the user selected and the current connector capabilities.
